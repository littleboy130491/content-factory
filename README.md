# Content Factory

Setiap tema punya satu folder di `project/<nama-tema>/`. Simpan brief, referensi khusus tema, dan hasil produksi di sana. Video, carousel, dan tulisan dari tema yang sama berbagi folder project. Tambahkan subfolder sesuai kebutuhan produksi.

| Folder | Kegunaan |
| --- | --- |
| `resources/insight/` | Pengamatan yang bisa memunculkan ide untuk beberapa tema. |
| `resources/knowledge/` | Pengetahuan editorial dan produksi lintas tema. |
| `resources/tools/` | Alat bantu bersama. |
| `resources/skills/` | Skill yang bisa dipakai ulang. |
| [resources/video/](resources/video/README.md) | Panduan, diary, template, dan skrip produksi film AI. |

`inputs/` dan `outputs/` menyimpan pekerjaan legacy. Lanjutkan revisinya di lokasi asal agar link board tetap berlaku.

Panduan editorial ada di [AGENTS.md](AGENTS.md).
